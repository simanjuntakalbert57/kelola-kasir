Penjualan per Produk — kartu di Ringkasan

DEAR-161 (rev. 2) · Gaya Arah A "Jus Hangat" (token sama dengan owner.html dan owner-dark.html), terang + gelap, desktop + HP. Tahap desain saja. Mengikuti arahan investor: "tempel di ringkasan aja, tanpa ada menu sidebar yang baru". Tidak ada menu sidebar, tab, atau route baru. Data di mockup adalah contoh.

Ringkasan keputusan desain

  • Tempat: kartu "Penjualan per Produk" di halaman Ringkasan (/), menggantikan kartu "Top produk". Sidebar dan tab bawah HP tidak berubah.
  • Filter: memakai filter periode dan cabang Ringkasan yang sudah ada. Tidak ada filter kategori (dihapus agar kartu tetap ringan); di dalam kartu hanya ada cari produk dan sortir.
  • Daftar: 8 baris teratas (cup terbanyak) + tombol "Lihat semua 12 produk" yang membuka daftar penuh di dalam kartu (tanpa pindah halaman). Kolom: produk, cup, total Rp, % omzet. Produk 0 penjualan ditandai "Belum terjual" dan hanya tampil di daftar penuh/hasil cari.
  • Detail: ketuk baris (mis. Jus Mangga) membuka panel samping 470px di desktop (daftar tetap terlihat, baris aktif ditandai) dan bottom sheet setinggi layar penuh di HP. URL /?produk=<id> agar bisa dibagikan; menutup panel menghapus parameter. Tanpa route baru.
  • Ekspor Excel: tombol di kepala kartu.
  • Angka: transaksi paid tidak terhapus; cup = semua item minuman (DEAR-153/154).

6. Spesifikasi untuk implementasi

ElemenPerilaku
RuteTidak ada route baru. Tetap /; produk terpilih di query /?produk=<productId>. Memuat URL dengan parameter langsung membuka panel/sheet. Filter periode dan cabang mengikuti state/query Ringkasan yang ada. ID tidak dikenal: panel tidak dibuka, toast "Produk tidak ditemukan".
KartuMenggantikan "Top produk". Kepala: judul, subjudul "Mengikuti filter di atas", Ekspor Excel. Lalu cari + sortir. Daftar 8 baris (HP: 5). "Lihat semua N produk" memperluas di tempat (tinggi kartu bertambah, tombol berubah "Tampilkan 8 teratas"); fokus tidak pindah.
TabelProduk (nama + kategori), Cup, Total Rp, % omzet (angka + bar). Sortir lewat header (desktop, aria-sort) atau menu "Urut" (HP): Cup (default), Total Rp, % omzet, Nama. Baris = tombol dengan target ≥48px; baris aktif berlatar tint + aria-current. Nol penjualan: teks abu + lencana "Belum terjual".
% omzetTotal produk ÷ total omzet semua produk pada filter yang sama (bukan hanya baris yang sedang dicari).
Panel / sheetDesktop: panel kanan 470px, menyusutkan area kartu (bukan overlay penuh), tombol Tutup + Esc. HP: bottom sheet tinggi hampir penuh, tarik ke bawah/tombol Tutup untuk menutup; fokus dikembalikan ke baris pemicu. Isi (urutan): kartu Cup / Total Rp / Harga rata-rata / Kontribusi omzet + delta vs periode sebelumnya (ikon + teks, tidak hanya warna), tren, Tunai vs QRIS, per cabang (hanya pemilik + "Semua cabang"), per kasir, jam paling laris (opsional).
TrenPer hari; "Hari ini" atau rentang ≤3 hari otomatis per jam; toggle Per hari/Per jam. Hari tanpa penjualan tampil 0 (zero-filled). Ada teks alternatif ringkas.
Ekspor ExcelSeluruh daftar produk sesuai filter Ringkasan (bukan hanya baris terlihat): Produk, Kategori, Cup, Total Rp, % omzet, periode, cabang. Tombol "Menyiapkan…" lalu unduh; galat lewat toast.
AksesibilitasKontras mengikuti token Arah A (≥4.5:1 terang dan gelap). Fokus terlihat 3px. Perubahan filter/hasil cari diumumkan aria-live="polite". Sheet/panel: role="dialog" dengan label "Detail <nama produk>".

7. Kebutuhan API (untuk Tech Lead / Backend)

Tidak berubah dari rev. 1 kecuali kategori. Sudah ada: GET /reports/sales?group_by=product dan /dashboard/sales-series, keduanya hanya outlet milik token (principal.outletId) dan tanpa pemilih cabang.

KebutuhanCatatan
1. Daftar produk + cup + Rp + % omzetPerluas /reports/sales?group_by=product: tambah items_sold (definisi DEAR-153/154), nama kategori, share_pct, produk 0 penjualan tetap dikembalikan (left join dari katalog), tanpa limit. Tambah outlet_scope=current|all seperti di summary, q, sort. Filter kategori tidak diperlukan.
2. Detail satu produkEndpoint baru, mis. GET /reports/products/:id: items_sold, revenue, average_price, share_pct, compare_previous_period{items_sold_change_pct, revenue_change_pct}, by_payment_method[], by_outlet[] (hanya scope all), by_employee[], peak_hour.
3. Tren per produkGET /reports/products/:id/series?granularity=hour|day, zero-filled, batas jam sama dengan MAX_HOURLY_DAYS.
4. EksporPola CSV/XLSX yang ada (B-12): GET /reports/sales/export?group_by=product&format=xlsx dengan filter yang sama.
5. PeranManajer: scope dipaksa ke outlet token; outlet_scope=all ditolak 403.
6. Definisi angkaHanya paid tidak terhapus, WIB business day (mohon Tech Lead konfirmasi perlakuan void_requested agar sama dengan dashboard).
7. Top produk/dashboard/top-products tidak lagi dipakai UI setelah kartu ini menggantikannya; boleh dibiarkan.

8. Asumsi dan pertanyaan terbuka

  • Asumsi: peran Manajer ada dan terbatas per cabang. Bila belum, bagian 4 diabaikan.
  • Asumsi: filter periode/cabang Ringkasan sudah mendukung "Hari ini / 7 hari / Bulan ini / Rentang" dan "Semua cabang". Kartu tidak menambah filter.
  • Asumsi: produk non-minuman (bila ada) tampil dengan Cup "–".
  • Perubahan dari rev. 1: filter kategori dihapus; jika dibutuhkan, tambahkan sebagai chip kecil di dalam kartu.
  • Untuk diskusi: panel desktop 470px menyempitkan kartu tabel di layar <1280px; usulan, panel menjadi overlay di bawah 1280px.
  • Untuk investor: jam paling laris masuk rilis pertama atau ditunda?
