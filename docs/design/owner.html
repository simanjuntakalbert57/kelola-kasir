Dashboard Owner · Spesifikasi handoff Arah A “Jus Hangat”

Dokumen ini menggantikan hi-fi gelap lama (DEAR-5/DEAR-40). Terang-hangat, krem + oranye jeruk, Nunito, kartu 24px, tombol pil, ikon Lucide. Untuk Frontend Engineer: salin §1 token ke @theme di apps/dashboard/src/styles.css, lalu ikuti komponen (§2), AppShell (§3), halaman (§4), dan copy (§5). Aplikasi kasir tetap gelap dan tidak berubah.

Asumsi (keputusan Albert di DEAR-62 belum dijawab; dipakai rekomendasi CoS)

  • Waktu mulai: implementasi sesudah rilis MVP (±2 Nov). Dokumen ini hanya spesifikasi.
  • Aturan “rame / sepi”: bandingkan omzet hari ini dengan rata-rata hari yang sama selama 7 hari terakhir; ≥ +15% “rame”, ≤ −15% “sepi”, di antaranya “normal”. Data < 7 hari: kalimat disembunyikan.
  • Sapaan: “Pak <nama depan>” dari profil owner; tanpa nama: “Halo!”.
  • Istilah: “void” menjadi “batal” di seluruh UI owner. API, kontrak, dan nama rute /void tidak berubah (kata di URL tidak terlihat pengguna).
  • Data pada mockup hanyalah contoh. Nama toko “Jus Bu Rini” adalah placeholder dari outlet.name.

Dampak API: tidak ada

Semua kebutuhan data sudah ada: omzet + compare_previous_period, daftar transaksi, shift, produk/kategori, pegawai, perangkat, pengaturan toko, permintaan void. Satu hal murni sisi klien: aturan rame/sepi memakai ringkasan harian 7 hari yang sudah bisa diambil dari endpoint laporan; bila Frontend mendapati endpoint itu tidak menyediakan rincian harian, tandai di issue (bukan perubahan API yang diminta sekarang). Lencana jumlah persetujuan batal memakai daftar void berstatus menunggu yang sudah dimuat Ringkasan.

6. Daftar periksa aksesibilitas (untuk QA)

  • Teks ≥ 4,5:1 (semua pasangan tercantum di §1; satu-satunya di bawah, teks tombol nonaktif 4,4:1, dikecualikan WCAG 1.4.3).
  • Batas input/tombol sekunder ≥ 3:1 (line-strong 4,6:1 terhadap putih).
  • Status tidak hanya warna: semua badge dan selisih kas memakai ikon + teks (+ tanda ▲▼ pada selisih).
  • Target sentuh ≥ 44×44 untuk semua kontrol (termasuk tombol ikon, chip, tab 52, baris 64).
  • Outline fokus 3px focus terlihat di semua kontrol; urutan Tab sesuai urutan visual; dialog/sheet mengunci fokus dan menutup dengan Esc.
  • prefers-reduced-motion mematikan animasi. Grafik tetap punya teks (peran ARIA + ringkasan kalimat).
  • Zoom 200% dan layar 320px: tanpa gulir horizontal (kartu menumpuk, baris membungkus).
