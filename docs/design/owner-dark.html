2. Perilaku pemilih tema

  • Lokasi: Pengaturan → kartu baru "Tampilan" (paling atas), segmented control 3 opsi: Terang · Gelap · Ikuti perangkat. Pintasan cepat: ikon bulan/matahari di header (desktop: pojok kanan atas; HP: header Ringkasan) yang bergantian Terang↔Gelap. Satu tap.
  • Default: "Ikuti perangkat" (prefers-color-scheme); jika pengguna belum memilih, desktop/HP bermode gelap langsung gelap. Catatan: Albert bisa mengubah default ke Terang bila ingin (lihat asumsi).
  • Simpan: localStorage kunci kk-theme = light|dark|system, per perangkat/peramban. Tanpa API.
  • Tanpa kedip: skrip inline kecil di <head> index.html memasang data-theme pada <html> sebelum render. Ubah juga <meta name="color-scheme"> dan theme-color.
  • Transisi: background/warna 150ms; nonaktif saat prefers-reduced-motion.
  • Pilihan terpilih memakai ikon + teks (bukan warna saja); label aksesibel role="radiogroup", target ≥44px.

4. Cara pasang (Frontend)

/* styles.css — tema terang tetap di @theme; override gelap lewat atribut data-theme */
@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));

:root { color-scheme: light; }
[data-theme='dark'] {
  color-scheme: dark;
  --color-bg:#1A130D; --color-surface:#261C14; --color-ink:#F7EBDD; --color-muted:#C4AE98;

/* Wajib: komponen memakai var(--color-pri-ink) untuk teks di atas tombol utama (bukan text-white). */

<!-- index.html <head>, sebelum CSS -->
<script>
 (function(){var p=localStorage.getItem('kk-theme')||'system';
  var d=p==='dark'||(p==='system'&&matchMedia('(prefers-color-scheme: dark)').matches);
  document.documentElement.dataset.theme=d?'dark':'light';})();
</script>

Dengarkan matchMedia('(prefers-color-scheme: dark)') saat pilihan = "Ikuti perangkat" agar ikut berubah langsung.

5. Aturan komponen di mode gelap

  • Tombol utama: isi pri dengan teks gelap pri-ink (putih di atas #FB923C hanya 2,3:1 — dilarang). Teks putih hardcoded harus diganti token.
  • Hero gradien (kartu omzet): terang memakai gradien #C2410C→#9A3412 dengan teks putih; gelap memakai permukaan surface biasa dengan angka berwarna pri, tanpa gradien.
  • Kartu: beda dari latar lewat warna permukaan + batas 1px line, bukan bayangan.
  • Status (Lunas, Menunggu, Dibatalkan, Nonaktif) tetap ikon + teks; pasangan warna di atas semuanya ≥9:1.
  • Grafik: batang bar, puncak pri; segmen tunai cash, QRIS ok; sumbu/label muted.
  • Sidebar: permukaan #211810, item aktif tint/tint-ink.
  • Gambar produk: tetap apa adanya, beri radius + batas 1px line; placeholder pakai tint.
  • Pratinjau struk (Pengaturan): tetap kertas putih/teks gelap di kedua mode, karena meniru cetakan.
  • Layar login: ikut tema; pemilih tema ikon kecil di pojok.
  • Skeleton: surface → #33271D bergeser.

6. Asumsi

  • "Redesign baru di UI owner" = Arah A Jus Hangat (DEAR-63/66), saat ini terang; kode lama dashboard bertema gelap v3 hijau yang digantikannya.
  • Preferensi tersimpan per perangkat, bukan per akun (tanpa perubahan API).
  • Default "Ikuti perangkat". Jika ingin default Terang, cukup ubah nilai awal kk-theme.
  • Cakupan: semua halaman owner (Login, Ringkasan, Transaksi, Shift & Kas, Produk, Pegawai, Perangkat, Pengaturan, Persetujuan batal) memakai token yang sama, tanpa layout baru.
  • Tidak ada dampak API/backend. Aplikasi kasir mobile sudah gelap dan tidak diubah.

7. Cara uji

  • Ganti ke Gelap, muat ulang: tidak ada kedip terang. Ubah tema OS dengan pilihan "Ikuti perangkat": berubah langsung.
  • Cek kontras semua status di tiap halaman ≥4,5:1 teks, ≥3:1 ikon/batas; fokus terlihat; tidak ada text-white/hex hardcoded tersisa (grep).
