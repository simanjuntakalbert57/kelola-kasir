Impor Produk dari Excel / CSV

Spesifikasi DEAR-113 (inisiatif parent DEAR-112), 30 Okt 2026. Gaya Arah A "Jus Hangat", token sama dengan owner.html dan owner-dark.html (tanpa token baru). Aplikasi kasir tidak berubah. File contoh ada di folder impor-produk/.

0. Ringkasan & asumsi

  • Alur 3 langkah di satu halaman (/produk/impor): 1 Unduh template → 2 Unggah → 3 Periksa lalu simpan. Dari halaman Produk lewat tombol Impor produk (sekunder, di sebelah "Tambah produk").
  • Jumlah tap/klik owner (file sudah diisi): Impor produk (1) → Pilih file (2, atau tarik file = 1) → Simpan (3). Langkah 1 (unduh) hanya sekali di awal.
  • Unggah otomatis memeriksa begitu file dipilih (tidak ada tombol "Periksa" terpisah). Pratinjau muncul di halaman yang sama; tidak ada yang tersimpan sebelum Simpan.
  • Simpan dinonaktifkan selama ada error (all-or-nothing). Teks bantu menjelaskan alasannya; tombol "Unggah file perbaikan" tampil di dekatnya. Disabled memakai aria-disabled sehingga tetap terbaca screen reader.
  • Status tidak hanya warna: ikon + teks (＋ Baru, ↻ Diperbarui, ✕ Error). Baris error diberi latar merah muda dan alasan tepat di bawah barisnya.
  • Nomor baris = nomor baris di Excel (baris judul = 1, data mulai baris 2), sehingga "Baris 7" langsung ketemu di file owner.
  • Asumsi untuk Tech Lead (mohon konfirmasi): (a) nama sama dua kali di dalam satu file = error E-NAMA-GANDA; (b) panel Pratinjau menampilkan semua baris sampai 500 (HP: kartu, desktop: tabel, bisa digulir; filter Semua/Baru/Diperbarui/Error); (c) API mengembalikan per baris: nomor baris, nilai, status (baru/diperbarui/error), kode error, dan untuk "diperbarui" nilai lama harga; (d) simpan memakai hasil validasi ulang di server (F-KADALUARSA bila data berubah); (e) nama header kolom persis huruf kecil nama, kategori, harga, favorit, aktif, urutan kolom bebas, huruf besar/kecil header diabaikan; (f) kolom ekstra diabaikan; (g) CSV dari template memakai koma + UTF-8 BOM (Excel Indonesia membuka benar); unggahan boleh ; atau ,; (h) pratinjau "Daftar error (.csv)" unduhan sisi klien, opsional (Could).
  • Asumsi pengguna: owner kedai jus, biasa memakai Excel atau HP, bukan teknis. Bahasa sederhana, hindari istilah "validasi", "parsing", "import".

1. File template

FileIsi
impor-produk/template-produk.xlsxSheet Produk: header oranye (nama, kategori, harga, favorit, aktif) + 2 contoh (Jus Jeruk, Jus Alpukat), baris judul dibekukan. Sheet Petunjuk: cara mengisi, arti kolom, contoh harga (15000, 15.000, Rp15.000), arti ya/tidak, batas 500 baris/2 MB, aturan "nama sama = diperbarui".
impor-produk/template-produk.csvHeader sama + 2 baris contoh sama. UTF-8 dengan BOM, pemisah koma.
impor-produk/contoh-bermasalah.csvUntuk uji QA dan pratinjau di layar C: berisi harga 15.000, Rp17.000, harga kosong, harga "lima belas ribu", nama kosong, favorit "mungkin".

Catatan: sheet Petunjuk berada setelah sheet Produk, sehingga parser cukup membaca sheet bernama Produk (fallback: sheet pertama).

F. Spesifikasi untuk Frontend

  • Rute: /produk/impor (breadcrumb "← Produk"). Satu komponen dengan state: idle → dragover → checking → preview(errors|ready) → saving → success; juga fileError.
  • Dropzone: elemen <button>/label yang bisa difokus, Enter/Spasi membuka pemilih file, accept=".xlsx,.csv", juga terima drop. Border dashed 3px; saat drag border + latar --pri/--tint. Di HP hanya tombol "Pilih file" (tanpa teks "Tarik file").
  • Ringkasan = 3 ubin (role="status", umumkan "2 baru, 1 diperbarui, 4 error"). Ubin bernilai 0 memakai warna netral.
  • Tabel pratinjau desktop (kolom: Baris, Nama, Kategori, Harga, Fav., Aktif, Status); HP berupa daftar kartu. Baris error: latar --need-bg, teks --need-ink, alasan di baris di bawahnya (role="alert" hanya untuk banner, bukan tiap baris). Default filter: Error bila ada, selain itu Semua. Gulir di dalam kartu, tinggi maks. 60vh; tombol Simpan menempel di bawah (sticky).
  • Simpan: aria-disabled="true" selama ada error; saat menyimpan tampil dialog status tanpa tombol tutup. Setelah sukses, fokus ke judul hasil dan umumkan jumlah.
  • Peringatan keluar: bila file sudah diperiksa dan belum disimpan, tombol Batal / ← Produk membuka dialog "Batalkan impor?".
  • Target sentuh ≥44px (HP); kontras memakai token Arah A yang sudah lulus 4,5:1; tidak ada warna sebagai satu-satunya penanda.
  • Unduh template: tautan ke endpoint template dari kontrak Tech Lead; nama file template-produk.xlsx / .csv.
  • Komponen baru (semua dari token yang ada): .drop .file .bar .sum .ftabs table.pv .rc .stick .tag; CSS contoh di halaman ini.
